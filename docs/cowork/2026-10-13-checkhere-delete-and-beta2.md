## 1. 체크히어 시간 삭제 방법 확인 (읽기만)

목표: 관리자가 학생의 **입실·퇴실 기록(시간)을 지우는 방법**을 정확히 알아내 연결 프로그램(`checkhere/collector.mjs`의 `write`)이 똑같이 따라 하게 만드는 것.
지금 연결 프로그램은 수정창의 `#modifyTime`(시간)과 `#memoByAdmin`(메모)을 채우고 `변경`을 누릅니다. 시간 칸이 비면 오류로 멈춥니다.

1. 수집 PC 크롬(체크히어 로그인 상태)에서 아무 반·지난 교육일의 **출결상세** 화면을 연다.
2. 입실 기록이 있는 학생 한 명의 **입실** 칸을 눌러 수정창을 연다. 아래를 기록한다.
   - 화면 캡처 1장(학생 이름·전화번호는 가려서)
   - 개발자 도구(F12) → Elements에서 수정창 전체를 선택 → 우클릭 **Copy → Copy outerHTML** → 텍스트 파일 `modal-entry.html`로 저장(이름·전화번호는 `홍길동`·`0000`으로 바꾸기)
   - 입력 칸 목록: id/name/type, 시간 칸이 `input type=time`인지 텍스트인지, 비울 수 있는지(지우기만 해 보고 **변경은 누르지 않기**)
   - 버튼 목록과 글자: `변경`, `취소`, `닫기`, **`삭제`가 있는지**, 있으면 위치와 정확한 글자
3. 같은 학생의 **퇴실** 칸 수정창도 같은 방법으로 `modal-exit.html`, 캡처 1장.
4. 수정창 밖에 기록을 지우는 다른 곳이 있는지 본다(행의 … 메뉴, 체크박스+삭제 버튼, 출결 기록 관리 메뉴 등). 있으면 캡처와 정확한 메뉴 이름.
5. 외출(나감·들어옴) 기록도 지우는 곳이 있는지 같은 방법으로 확인(있으면 캡처·outerHTML).
6. 개발자 도구 Network 탭을 켜 둔 채 수정창을 **열고 닫기만** 했을 때 나가는 요청 이름(주소 끝부분)만 적는다. 요청 내용·쿠키·토큰은 복사하지 않는다.
7. 시험용 학생·시험용 반이 체크히어에 따로 있으면 알려 준다(있으면, 사용자가 허락한 경우에만 그 학생으로 실제 삭제를 한 번 해 보고, 삭제 전후 캡처와 확인창 문구를 남긴다). 없으면 실제 삭제는 하지 않는다.

결과는 `checkhere-delete-report.md` 한 파일로 정리한다.

```
## 입실 수정창
- 시간 입력: (예: <input id="modifyTime" type="time">, 비우기 가능/불가)
- 메모 입력: …
- 버튼: 변경 / 취소 / 삭제(있음·없음, 글자: "…")
- 삭제 시 확인창 문구: (실제로 누른 경우만)
## 퇴실 수정창
- …
## 수정창 밖의 삭제 방법
- …
## 외출 기록 삭제
- …
## 수정창 열 때 나가는 요청 이름
- …
## 시험용 학생·반
- 있음/없음
```
