## 하는 일 (순서대로)

`apps-script/beta2/README.md`의 「동기화 실행 시간 줄이기 반영 순서」 0~8단계를 그대로 따른다. 요약:

0. 지금 편집기의 `beta2`와 `Code.gs`가 저장소 기준(SHA-256 `11482b5d…`, `ef9ad3c0…`)과 같은지 확인. 다르면 멈추고 알린다. 두 파일 내용을 백업으로 복사해 둔다.
1. 서비스 + → Google Sheets API(`Sheets`, v4) 추가 → 저장.
2. `beta2` 내용을 새 `beta2.gs`로 통째로 교체 → 저장.
3. `Code.gs` 내용을 새 `Code.gs`로 통째로 교체 → 저장.
4. 배포 ①(`AKfycbxKN_…`)을 새 버전으로(새 배포 만들지 않음). 배포 ②는 사용자 지시대로.
5. 평일 09:10~18:00 안에서 편집기로 `b2SyncTick` 한 번 실행. 권한 창이 뜨면 hint.kpc로 승인.
6. 보고(값만): 스크립트 속성 `B2_SYNC_LAST`의 `mode`, `ms`, `t`, `legacyAdopted`, `writes`, `stats`, `errors`, `retries` / `B2_LEGACY_ADOPTED` / `B2_BOARD_DAY` / 출결원장 T열 중 `운영총괄 값:`·`운영총괄에는`·`같은 학생`으로 시작하는 칸 개수 / 실행 기록의 그 실행 시간.
7. **사용자에게 결과를 알리고 확인을 받은 뒤** `b2InstallTrigger` 실행(10분 간격으로 되돌림). 트리거 목록에 `b2SyncTick` 하나, 10분마다인지 확인.
8. 약 1시간 뒤 실행 기록에서 `b2SyncTick`의 실행 시간·시간 초과·실패 수, `onOpen`·`onEdit` 실행 시간을 보고.
