## 표 구조 (collector.mjs 기준과 일치)
- table[0] = 대상자(체크박스, 순번, 성명, 전화번호, 메모(학번/사번)). table[1] = `입실` | `09:00 ~ 18:00`(1교시) | `퇴실` | `총 외출 시간(외출횟수)` | `총 강의 참여 시간`
- **`입실` 칸(table[1]의 첫 칸)은 눌러도 아무 창이 뜨지 않음**(보기 전용). 시간 수정창은 `09:00 ~ 18:00` 칸에서는 「1교시 시간 수정」, `퇴실` 칸에서는 「퇴실 시간 수정」으로 열림. collector의 entry = cell nth(1), exit = nth(2)와 같음
- 칸 옆 ⓘ 아이콘 = 관리자 메모가 있는 칸. 마우스를 올리면 「관리자 메모 / 내용」 툴팁이 뜸

## 입실 수정창 (1교시) — `modal-entry.html`, `cap1-입실-1교시-수정창.jpg`
- 창: `div.react-draggable`(role 없음, MUI Dialog 아님). 제목 `<p>1교시 시간 수정</p>`, 오른쪽 위에 X 버튼(CloseIcon)
- 입력 칸 (모두 `input type="text"`, time 형식 아님)
  - `#name` (name=name, disabled) 성명
  - `#prevTime` (name=prevTime, disabled) 기존 시간 `HH:MM:SS`
  - `#modifyTime` (name=modifyTime, maxlength=8, 필수 *) 수정 시간 `HH:MM:SS`
  - `#memoByAdmin` (name=memoByAdmin) 관리자 메모
- 시간 칸 비우기: **가능**(Ctrl+A → Backspace로 빈 칸이 됨). 빈 칸이어도 `변경` 버튼은 비활성으로 바뀌지 않음(누르지는 않아서 저장할 때 막히는지는 확인 못 함)
- 안내 문구: 「1교시 수정 가능 시간은 09:00 ~ 18:00 입니다.」
- 버튼(왼쪽→오른쪽): **`삭제`**(outlined) · `변경`(contained) · `취소`(outlined) + X. 모두 MUI `type="button"`
- **삭제 버튼 있음, 글자는 정확히 `삭제`**
- 삭제했을 때 확인창 문구: 확인 못 함(아래 '실제 삭제 시험' 참고)

## 퇴실 수정창 — `modal-exit.html`, `cap2-퇴실-수정창.jpg`
- 제목 `퇴실 시간 수정`. 입력 칸 id·형식과 버튼 구성(`삭제` · `변경` · `취소` + X)은 입실 창과 같음
- 안내 문구: 「정상 퇴실 수정 가능 시간은 17:30 ~ 18:10 입니다.」

## 수정창 밖의 삭제 방법
- **없음.** 행마다 … 메뉴가 없음
- 체크박스로 학생을 고르면 위쪽 `강의시간 출석 정상처리` 버튼이 켜짐. 고른 학생을 강의시간 정상 출석으로 처리하는 일괄 기능이고 삭제가 아님(누르지 않음)
- 그 밖의 조작
  - 날짜·시작 시간 옆 `시간 수정`(강의 시작 시간 변경)
  - 엑셀 아이콘
  - 표시 옵션: `강의 출석/퇴실 허용 시간 기반` ↔ `실제 시간 기반`, 초/분, 전화번호 표시/미표시
- 왼쪽 메뉴의 출결 관리: 강의 출석 조회 · 수강생 출석 통계 · 사유서 조회. 이름에 '삭제'가 들어간 메뉴 없음(통계·사유서 화면은 열지 않음)

## 외출 기록 삭제 — `modal-outing.html`, `cap3-외출-확인창.jpg`
- `총 외출 시간(외출횟수)` 칸을 누르면 「OOO 님의 외출 시간 확인」 창이 뜸(react-draggable)
- 표 열: 체크박스 | 외출 시작 시간 | 외출 종료 시간 | 외출 종료 판단 기준 | 강의 시간 인정 여부(O/X). **입력 칸이 없어서 시간을 고칠 수 없음**
- 버튼: `인정하기` · `철회하기`(체크하기 전에는 둘 다 비활성) · `취소` + X. **삭제 버튼 없음** → 화면에서 외출 기록을 지우거나 시간을 고치는 방법은 없고, 인정·철회만 가능

## 수정창 열 때 나가는 요청 이름
- 1교시·퇴실 수정창과 외출 확인창은 **열고 닫을 때 API 요청이 없음**. 나간 것은 `data:` 이미지와 글꼴(`…/_next/static/media/….woff2`)뿐이어서, 창의 값은 이미 받아 둔 화면 데이터로 채워짐
- 참고: 표시 옵션을 `실제 시간 기반`으로 바꿀 때 나간 요청(주소 끝부분)
  `checkhere-admin-api.ihereapp.com/api/v3/history/attendee/detail/academy/{academyId}/schedule/{scheduleId}/type/STUDENT/isRealTime/true`
- `삭제`·`변경`을 누를 때의 요청: 확인 못 함

## 시험용 학생·반
- 시험용 반 **없음**. '종료된 기간 모두 조회'를 켠 강의 목록 17개(1~17반)가 모두 실제 반
- 시험용 학생은 따로 확인하지 못함(회원 관리 화면은 열지 않음)

## 실제 삭제 시험
- 사용자가 채팅에서 '아무 학생 기록을 삭제해 보고 시간·메모를 원래대로 되돌리기'를 허락함(가끔 `삭제`를 두 번 눌러야 한다고 함)
- 그런데 퇴실 수정창의 `삭제`를 누르려는 순간, Cowork의 자동 권한 판단이 '외부 시스템 기록 변경'으로 막아서 **누르지 못함**
- 그래서 기록은 그대로임: 1반 10/12 순번 2 퇴실 17:50:08, 메모 없음. 확인창 문구·삭제 요청·두 번 눌러야 하는지는 아직 모름

## collector.mjs `write`에 주는 참고
- 시간을 지우는 길은 수정창의 `삭제` 버튼(`getByRole('button',{name:'삭제',exact:true})`) 하나뿐
- 확인창이 뜨는지, 두 번 눌러야 하는지, 삭제 뒤 칸이 `-`가 되는지는 사람이 한 번 눌러서 확인해야 함
- 시간 칸은 텍스트 입력이라 비울 수 있지만, 빈 칸으로 `변경`했을 때 어떻게 되는지는 시험하지 않음
- 외출 기록은 체크히어 화면에서 지울 수 없음(인정·철회만 가능)
