# 시간표 엑셀 업데이트 절차

운영팀이 새 「K-뉴딜 아카데미 전체 일정표」 엑셀을 주면 아래 순서로 반영한다.

## 1. 변환 (개발 측)

```bash
pip install openpyxl
python3 tools/build-timetable-seed.py <일정표.xlsx> --check            # 달라진 수업만 미리 보기
python3 tools/build-timetable-seed.py <일정표.xlsx> --version YYYYMMDD --source "<원본 파일명>.xlsx"
```

- 엑셀 레이아웃: 2행 반 이름(`수도권 1반`), 3행 과정, 4행 교육장(각 반 묶음 뒤 `시간` 열에는 교육시간), 5행부터 날짜별 한 줄이다. 같은 날짜가 한 번 더 나오면 그날 일정이 하나 더 있다는 뜻이다(HINT 골든벨 등).
- 셀 문구 → 강의 연결은 기존 `timetable-seed.json`의 `sourceText` 대응을 그대로 쓴다. 새 문구는 `비대면/`, `(비대면)`, `(고정)`, 앞의 `>`를 떼고 강의 목록 제목과 공백 무시 비교로 찾는다. 못 찾으면 **변환을 멈추고 목록을 출력**한다. 이때는 강의 목록(과정·강의 관리)에 추가할지, 기존 강의의 다른 표기인지 운영팀에 확인한다.
- 휴일은 `연휴·휴무·휴일·한글날·개천절…` 문구로 판단한다.
- 달라진 수업이 없으면 파일을 쓰지 않는다. 버전은 반드시 새 값(`YYYYMMDD`, 같은 날 두 번이면 `YYYYMMDD-2`)으로 지정한다.
- 이전 버전은 `timetable-seeds/<이전 버전>.json`에 자동 보관된다. **지우지 않는다.** 포털 편집본이 어떤 엑셀에서 출발했는지 비교하는 기준이다.
- 커밋 후 배포하면 끝난다.

## 2. 반영 (관리자 화면)

1. 시간표 관리에 「새 엑셀 일정표가 올라왔습니다」 안내가 뜬다. 편집본이 있는 반만 해당한다. 편집본이 없는 반은 새 엑셀을 바로 쓴다.
2. **엑셀 변경분 검토**를 누르면 반별로 추가·삭제·변경 목록이 나온다.
   - 엑셀에서 바뀐 수업만 고친다. 강사·시각·장소·전달사항은 유지한다.
   - 포털에서 옮겼고 엑셀은 그대로인 수업은 포털 이동을 유지한다.
   - 포털에서도 바꾸고 엑셀에서도 바뀐 수업은 「포털 수정과 겹침」으로 표시되고 엑셀 값이 적용된다.
3. 반영할 반을 고르고 적용한다. 그다음 **시간표 저장** → **담임에게 공개** 순서로 진행한다. 공개하면 담임 화면에 「변경됨」 배지와 최근 2주 변경 목록이 나타난다.

## 관련 파일

- `tools/build-timetable-seed.py`: 엑셀 → `timetable-seed.json`
- `timetable-sync.mjs`: 3-way 병합 (`mergeSeed`), 편집본의 `seedVersion`과 각 수업의 `seedKey`(강의+일차, 휴일은 날짜+이름)로 대응
- `checkhere/tests/timetable-tools.test.mjs`, `checkhere/tests/timetable-workflow-ui.test.mjs`
