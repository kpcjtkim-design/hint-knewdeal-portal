불러오는 중…

  1. 체크히어 로그인 → 반마다 강의 연결 확인(이름 규칙 [N반]으로 못 찾는 반만 직접 고름)
  2. 교육생 명단이 있으면 불러오기(없어도 됩니다 — 체크히어 원문 명단으로 확인)
  3. 사람이 체크히어 마스킹을 해제한 뒤 「확인 안 된 반 모두 읽기」 → 반마다 맞음·명단에 없음·명단에만·겹침을 보고 고친 뒤 「이 반 확인」
  4. 운영포털 「체크히어 실시간」 화면(승인 계정)에서 「확인된 반 등록」 · 필요하면 아래에서 CSV로 내보내 시트에 붙여 넣기

0. 체크히어 로그인 · 마스킹 상태

체크히어 해제 상태 확인 중

마스킹 해제·연장·종료는 사람이 합니다: 연결 프로그램이 연 체크히어 창(같은 탭)에서 직접 하거나 위 「마스킹 해제 시작」을 누르고 메일로 받은 인증번호를 넣습니다. 연결 프로그램은 해제·연장·종료를 스스로 누르지 않습니다.

1. 반 → 체크히어 강의 연결

강의 이름이 규칙(예: [3반] …)에 맞으면 수집할 때 저절로 찾습니다. 이름이 다르거나 1기 강의와 헷갈리면 여기서 반마다 강의를 골라 연결해 주세요(이 PC에만 저장).

반반 이름지금 연결강의 고르기

2. 교육생 명단 불러오기(있으면)

엑셀에서 복사해 붙여 넣거나 CSV 글을 넣어 주세요. 칸: 반, 이름, 전화(전체 번호 또는 끝 4자리), 생년월일은 골라 맨 뒤에(예: 1999-03-02). 첫 줄에 머리말(반·이름·전화·생년월일)이 있으면 그 칸을 씁니다. 전체 번호는 학생 키만 만들고 저장하지 않습니다. 명단·생년월일은 이 PC에만 둡니다(등록·내보내기에 생년월일 없음). 반을 고르면 그 반 명단을 통째로 바꿉니다.

3. 반별 확인(마스킹을 해제한 동안 반마다 한 번)

원문 화면에서 반마다 그날 출결 화면을 한 번씩 읽어(빠른 수집, 수정창 없음) 명단과 체크히어 학생 번호를 맞춥니다. 해제 시간이 1분보다 적으면 그 반에서 멈추니 연장(또는 다시 해제)한 뒤 다시 누르세요. 줄을 고르면 아래에 자세히 나옵니다.

반강의명단원문 확인(맞음 · 명단에 없음 · 명단에만 · 겹침)이 반 확인등록

4. 등록 · 내보내기

등록은 운영포털 「체크히어 실시간」 화면에서 승인 계정으로 로그인한 사람이 「확인된 반 등록」을 눌러 합니다(2기 DB의 관리자만 보는 checkhereIdentities에 반마다 이름·끝 4자리·체크히어 학생 번호). 시트에 넣을지는 사용자가 정합니다: 아래 CSV(반, 이름, 끝 4자리, 체크히어ID)를 내려받거나 표로 복사해 붙여 넣으세요.

이 화면의 이름·끝 4자리·생년월일은 이 PC에서만 보입니다(작업 기록·중계·운영 포털로 가지 않음). 연결 프로그램 첫 화면 · 순차 수정 확인
